Many clients bring a **live** product, not a blank idea: crashes, slowness, old SDKs, store rejection.

First we read the code and store state: crashlytics, dependencies, OS versions. Then a list: security, UX, new features. Release uses a checklist for signing, privacy, screenshots, and ratings.
